extensions: 
- C# Dev kit

Breakdown:
- Entities Folder is to create the DB columns and enums or classes that are required to stored data
- Data Folder is to set the DB context

How to do a data migration for a table create or change: 
dotnet tool install -g dotnet-ef
dotnet ef migrations add "InitalCreate" -o Data/Migrations
dotnet ef database update

docker:
docker compose up -d
docker compose down
docker compose down -v (ONLY WHEN YOU WANT TO CLEAR THE ENTIRE DB)
